{# THE ONE ICON SET. Every workspace page draws from here and nowhere else. WHY A MACRO FILE AND NOT INLINE SVG PER PAGE. Icons were being hand-written into each template, so the same idea arrived in three shapes — a cart on one page, a bag on the next, a box on a third — and the workspace stopped looking like one product. A macro means "the orders icon" is a decision made once. THE FAMILY IS FIXED: 24×24 viewBox, stroke-based, no fill, `stroke-width: 2`, round caps and joins. Mixing a filled icon into a line set is the single most visible way a UI looks assembled rather than designed, so every path here is stroke-only and `currentColor` — the icon inherits whatever colour its context already decided. Every icon is aria-hidden. They sit beside real text, always; an icon that is the only label is a guess for a sighted user and silence for everyone else.
